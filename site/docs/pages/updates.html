Updates

The thermostat, the integration and the app each update on their own. None of them needs the USB cable again.

The thermostat

A thermostat patched with updates on (the app's default with Home Assistant) shows an update entity, Fledge software, under Settings → Updates in Home Assistant. Press Install there.

  • Releases are signed. The thermostat checks the download's digest and signature before it installs.
  • If the new build doesn't come up, it rolls itself back to the one before, after three failed starts.
  • It checks once a day, whenever the Fledge integration updates, and when you press Check for Fledge update.

With updates off, it never checks, shows no update entity, and only a new patch from the app brings it a newer build.

Releases are signed with Ed25519 public key 7eIg9OAPKjpPeuXdvCXlOy+VAZfnSHDGOJY4HUIdgy8=.

The integration

Updates from the Marketplace (HACS) like any other. When it updates, it has the thermostat look for its own update straight away, since the two often come out together.

If they don't match, the thermostat says which version of the cards it understands, and a repair under Settings → Repairs asks you to update it.

The app

Release builds check for a newer release when they start and offer to install it. Builds you make yourself never update.

Test releases

New features go out as test releases (marked Pre-release on GitHub, versions like v0.10.0-rc.1) before they're released for everyone. To try them:

  • The thermostat: turn on its Fledgeling pre-releases switch in Home Assistant. Its update entity then offers test releases too.
  • The integration: in the Marketplace, open Fledge, choose Redownload from its menu, and pick the test version. Restart Home Assistant afterwards.

Use the two together: each test release's notes say which version of the other it needs. Found something wrong in one? Open an issue and say which test release you're on.
