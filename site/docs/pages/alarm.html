Alarm panels

Any alarm panel in Home Assistant can be a card. Arm it from the ring, and disarm it with the code entered on the ring.

Using it

  • Open the alarm's card, then choose to arm (its modes), Disarm or Cancel.
  • The code is entered with the ring: the digits sit round it. Turn to each and press; hold to rub one out.
  • When the entry delay starts, the thermostat lights straight into the code pad, the ring counting down. Going off, it shows red until disarmed.
  • Three wrong codes lock the pad for 30 seconds, longer each time. The code is never stored.

Setting it up

Add the alarm panel as a card in the Fledge panel, then:

  • Name each arm mode as it should appear on the Nest (or copy the names from an Alarmo card).
  • Say how long the code is, so the last digit sends it.
  • Turn off Take over the screen if you'd rather the countdown waited on the alarm's card than lit the thermostat.

With Alarmo

With Alarmo, the countdown is in seconds, the screen names the sensor that set it off, and a door left open can be armed past.

Alarm cards need the thermostat on Fledge v0.7.0 or later.
