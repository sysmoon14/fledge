Troubleshooting

The app doesn't see the thermostat

  • Use a USB cable that carries data. Charge-only cables are the usual cause.
  • Plug into the USB port on the back of the detached display, not the power-only port on a European stand or Heat Link base.
  • On Linux, add the udev rule and reconnect the thermostat.

Windows: ACM interface for 18d1:4ee0 did not appear

An Android driver installed earlier has claimed the recovery device, so its console gets no COM port. While the thermostat is in recovery:

  1. Open Device Manager and find Android Bootloader Interface.
  2. Update driver → Browse my computer → Let me pick → Universal Serial Bus devices → USB Composite Device.
  3. Run the app again. The choice persists.

macOS won't open the app

It is signed ad hoc, not notarized. Run xattr -dr com.apple.quarantine Fledge.app, or allow it under System Settings → Privacy & Security.

Home Assistant shows the thermostat offline

It shows online only while the thermostat's app calls in to nestlocal and nestlocal is connected to the broker. Check that the thermostat is on Wi-Fi (Settings → Network on the Nest) and reaches the broker address you gave it, with the right user and password.

The Nest shows error H71 or H74

On a Heat Link model with no Heat Link (or with Zigbee or Thread on), the Nest has to be told it's wired to its base. Turn on the Nest's Works With Nest boiler switch in Home Assistant (the thermostat reboots into it), or patch again answering Wired to the Nest's base, or no Heat Link under Your heating.

No cards on the screen

  • Is the Fledge integration set up, with some devices picked?
  • Is Wake to set to the thermostat? Then it wakes as the Nest always did. Set it to the Device chooser.
  • Is there a repair under Settings → Repairs asking you to update the thermostat? See Updates.

The glance never shows

The Nest only sees someone across the room while its own Farsight is on (any of its choices) in Nest's settings. See The glance.

Still stuck?

Open an issue with:

  • how you ran it (app or command line, with the options used) and your computer's OS;
  • the full log of the run (the app's Logs page keeps every run's);
  • what the thermostat's screen showed.

Issues about the integration go to fledge-homeassistant.
