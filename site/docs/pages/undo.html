Back up and undo

A whole-NAND backup, bad blocks and all, puts the thermostat back exactly as it was.

Back up

  • In Set up, Review's Back up, then patch (the default) saves it before patching.
  • Any time, the app's Backups page → Back up unit, or fledge backup on the command line.

The backup is checked with a second read of the NAND. Keep the file somewhere safe: the app lists the images it keeps on its Backups page.

fledge verify compares a backup with what's on the thermostat now.

Go back to stock

Restore to unit on the Backups page (or fledge restore) writes the backup back to the thermostat.

Each patch

On the command line, --backup also saves the original root volume before each patch. The patch keeps the stock nlclient beside the run log, and can always be undone.

Just want your devices off the screen? You don't need to restore: remove the Fledge integration, or turn off what it wakes to. See Removing it.
