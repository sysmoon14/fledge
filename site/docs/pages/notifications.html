Notifications

fledge.notify puts a message on the thermostat's screen, waking it with a chime: an icon, a title and a message, or a camera's picture, taken there and then, filling the round screen.

Answering one

  • Press to answer it, hold to dismiss it. Either fires a fledge_notification event with its tag and action (pressed for a press), so an automation can act on the answer.
  • It dismisses itself after timeout seconds (30 by default), and fledge.dismiss takes it back.
  • A notification's answer is only taken while that notification is showing.

Fields

FieldWhat it is
messagerequiredThe text.
titleA title above it.
iconAn mdi: icon.
cameraA camera entity: its picture, taken now, fills the screen.
timeoutSeconds before it dismisses itself, 3 to 3600. Default 30.
tagNames it, for fledge.dismiss and the answer's event.
thermostatWith more than one Nest, which ones show it (device IDs). All of them when left out.

The panel's Notifications tab writes one for you, sends it to the Nest to try, and copies it as an action.

The doorbell

Someone rings, and the thermostat shows who's there.

automation:
  - alias: Doorbell on the Nest
    triggers:
      - trigger: state
        entity_id: binary_sensor.front_door_ding
        to: "on"
    actions:
      - action: fledge.notify
        data:
          title: Someone's at the front door
          message: Front door
          camera: camera.front_door
          tag: doorbell
          timeout: 60

Acting on the answer

A press on the Nest locks the back door.

automation:
  - alias: Back door left open
    triggers:
      - trigger: state
        entity_id: binary_sensor.back_door
        to: "on"
        for: "00:10:00"
    actions:
      - action: fledge.notify
        data:
          title: Back door open
          message: Press to lock it when it's shut.
          icon: mdi:door-open
          tag: back_door
      - wait_for_trigger:
          - trigger: event
            event_type: fledge_notification
            event_data: { tag: back_door, action: pressed }
        timeout: "00:02:00"
        continue_on_timeout: false
      - action: lock.lock
        target:
          entity_id: lock.back_door

Taking one back

action: fledge.dismiss
data:
  tag: doorbell
